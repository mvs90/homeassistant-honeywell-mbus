# Security

Do not include credentials, raw private telegrams, IP addresses or meter serials
in a public issue. The integration's downloadable diagnostics redact host and
serial data. Use GitHub private vulnerability reporting for security reports when
available; do not publish an exploit or secret in an ordinary issue.

The integration has no cloud connection or gateway management credentials. Its
configured raw TCP endpoint must be part of the user's trusted local network.
Configuration backup/remote access security is the responsibility of the HA host.
